# 马克思主义哲学（2023）互动复习网页项目

这是一个用于小组作业的项目骨架仓库，目标是后续基于你上传的资料，生成一个**互动式、动态思维导图 + 题目练习**网页。

---

## 一、项目目标

计划实现的网页功能：

1. 以思维导图结构展示《马克思主义哲学（2023）》复习内容。
2. 导图支持动态展开：学生每回答一步，相关树枝逐步伸展。
3. 在合适节点旁提供“进入测试题”按钮。
4. 点击按钮后进入题目页面，包含：
   - 客观题（如单选、多选、判断）
   - 主观题（如简答、论述）
5. 后续可根据学习进度继续扩展节点与题库。

## 三、建议操作流程（详细版）

### Step 1：准备并上传素材

1. 把思维导图内容整理后放入 `mindmap/`。
2. 把题目内容整理后放入 `questions/`。
3. 文件格式可先按你们习惯准备（如 `.md`、`.json`、`.txt`、`.xlsx` 导出内容等）。

> 建议尽量保证命名清晰，例如：
> - `mindmap/chapter-01.md`
> - `questions/chapter-01-objective.md`
> - `questions/chapter-01-subjective.md`

### Step 2：补充规则说明（可选但推荐）

建议在素材中明确以下信息，后续生成网页会更稳定：

- 每道题属于哪个导图节点（章节/知识点）
- 客观题答案与解析
- 主观题参考要点（评分点或关键词）
- 哪些节点需要出现“进入测试题”按钮

### Step 3：让 Agent 生成网页

当你上传完素材后，可以直接给 Agent 下达类似指令：

- “请基于 `mindmap/` 和 `questions/` 的内容，生成一个互动式复习网页。”
- “导图按答题进度动态展开，在指定节点显示进入测试按钮。”
- “题目页面同时支持客观题和主观题，并显示答案/参考要点。”

Agent 将根据仓库中的素材继续创建网页代码（例如前端页面、数据读取逻辑、交互流程等）。

### Step 4：本地预览与迭代

后续网页生成后，按 Agent 提供的启动方式本地预览，重点检查：

- 导图是否按预期逐步展开
- 题目按钮跳转是否正确
- 客观题判分与主观题展示是否正常
- 内容是否完整覆盖课程复习点

根据检查结果继续迭代数据和页面。

## 四、后续协作建议

- 小组内先统一知识点层级（章 → 节 → 核心概念），再整理题目。
- 先做“最小可用版本”（少量章节 + 基础题型），再逐步扩展。
- 每次新增内容尽量保持文件命名和结构一致，便于自动化处理。
